# Code of Conduct

**The short version:** be the person you would want to respawn next to.
This is a game first and a codebase second — treat every contribution
space like a lobby you would happily queue in.

## Scope

This Code of Conduct covers the project's spaces: this repository (issues,
pull requests, code review, discussions), the project's community servers
and lobbies, and any channel the maintainers designate as official
(Discord/Matrix/etc. when one exists).

## What we ask

1. **Assume good faith.** Most review comments and queue frustration are
   about the code or the ping, not about you.
2. **Critique the change, not the person.** "This trusts a client number
   for damage" beats "your damage code is bad."
3. **Match the room's language to the room's work.** Design debate in
   issues, implementation in PRs, socializing in the lobby.
4. **Credit where it's due.** The asset-license checklist exists so
   nobody's work gets absorbed unattributed — use it.
5. **Call it out, then let maintainers handle it.** If something violates
   this CoC, report it to a maintainer (issue with the label `conduct` or
   any channel you prefer, including a private one). Maintainers respond
   within 3 days; the reporter's channel choice is respected.

## What we don't

Harassment or slurs (spoken or written), sustained disruption (one bad
review exchange is human; a pattern is not), dismissal of the project's
ground rules (license compatibility and original IP are not preferences —
see CONTRIBUTING.md), and out-of-scope pile-ons (quote only what you are
replying to).

## Enforcement

Maintainers may edit or remove comments, issues, and PRs that violate this
Code of Conduct, and may ban temporarily or permanently. Outcomes are
communicated to the people directly involved; private conversations stay
private. Decisions about bans are reviewed by at least two maintainers.
This project's maintainer set is small and human — when in doubt, ask a
maintainer how to proceed before escalating.
